# Раскадровка

Workflow **Preview** сохраняет раскадровку из 25 кадров в артефакте **storyboard**. Кадры идут по порядку, слева направо и сверху вниз. Индексы кадров лежат в `src/data/timeline.ts`.

Для локального экспорта после `npm run audio` выполните `npm run storyboard`. Результат доступен в `out/storyboard.jpg`.
